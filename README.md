# PRD refinado  no Copliot Web:

## PRD – Aplicativo de Organização de Finanças Pessoais

## Contexto
Criar um aplicativo de organização financeira pessoal que funcione por meio de conversas em linguagem natural.
O objetivo é simplificar o controle financeiro, eliminando formulários complexos e planilhas, oferecendo uma experiência fluida e acessível.

## Problema
Usuários frequentemente abandonam apps de finanças porque:
- Exigem entrada manual excessiva.
- Oferecem pouca personalização.
- Tornam o processo burocrático e pouco intuitivo.

### O aplicativo busca resolver isso com uma experiência conversacional e recomendações automáticas de economia.

## Público-Alvo
- Pessoas que desejam iniciar o controle financeiro de forma prática.
- Usuários iniciantes que não têm familiaridade com planilhas ou apps tradicionais.
- Pessoas que valorizam simplicidade e linguagem acessível.
- Todos os perfis de usuários, considerando diversidade de idade, nível de escolaridade, acessibilidade digital e necessidades especiais.

## Funcionalidades-Chave
1. Registro de gastos via chat em linguagem natural.
2. Classificação automática das transações (ex.: alimentação, transporte, lazer).
3. Definição e acompanhamento de metas financeiras (ex.: guardar R$200/mês).
4. Agente Financeiro que fornece dicas de economia personalizadas.
5. Relatórios simples e visuais (gráficos e resumos adaptados ao perfil do usuário).
6. Design Universal: interface inclusiva, acessível e intuitiva para o maior número possível de pessoas, incluindo recursos como contraste adequado, suporte a leitores de tela e linguagem clara.

## Entregável da IA
- Plano de MVP com:
  - Principais telas:
    - Tela de chat (entrada de dados e interação).
    - Tela de metas financeiras.
    - Tela de relatórios/resumos.
  - Recursos necessários:
    - Processamento de linguagem natural (NLP).
    - Motor de categorização automática.
    - Sistema de recomendações.
    - Visualização de dados simples e acessíveis.
  - Validação inicial:
    - Testar com grupo diverso de usuários (diferentes idades, níveis de experiência digital).
    - Medir engajamento (quantidade de interações no chat).
    - Avaliar clareza das dicas e relatórios.
    - Verificar acessibilidade (uso com leitores de tela, facilidade de navegação).

# FinançasAI – Resumo de Funcionalidades

## Funcionalidades previstas no PRD
- Registro de gastos via chat em linguagem natural.
- Classificação automática das transações.
- Definição e acompanhamento de metas financeiras.
- Agente Financeiro que fornece dicas de economia personalizadas.
- Relatórios simples e visuais adaptados ao perfil do usuário.
- Design Universal: interface inclusiva, acessível e intuitiva para o maior número possível de pessoas.

## Funcionalidades visíveis no protótipo (print da tela)
- Tela de login com campos de email e senha.
- Mensagem de boas-vindas: “Bem-vindo de volta! Entre para acessar suas finanças”.
- Botão de acesso (“Entrar →”) para autenticação.
- Link para criação de conta (“Não tem conta? Criar conta”).
- Design limpo e minimalista, com cores claras e destaque em verde.

## Síntese
O protótipo já mostra a estrutura inicial de acesso ao sistema (login e cadastro), que é o primeiro passo para o MVP descrito no PRD.  
A partir daí, o próximo desenvolvimento deve incluir:
- Tela de chat para registro de gastos.
- Tela de metas financeiras.
- Tela de relatórios simples.
- Implementação do Agente Financeiro.

## Roadmap de Desenvolvimento
1. **Autenticação**
   - Login e cadastro de usuários.
   - Recuperação de senha.
2. **Chat Financeiro**
   - Registro de gastos em linguagem natural.
   - Processamento de linguagem natural (NLP).
3. **Classificação Automática**
   - Motor de categorização de transações.
4. **Metas Financeiras**
   - Definição de objetivos.
